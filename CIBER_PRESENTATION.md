# CyberShield CIBER — presentation flow

## Commands

- `ciber` — enter the AI operator terminal directly.
- `cibershield` — launch the main CyberShield desktop application.
- `cibershield terminal` — launch the defensive security terminal.
- `ciber help` — show the CIBER action catalog.

## Natural-language examples

- `ciber loyihani tekshir`
- `ciber testlarni ishga tushir`
- `ciber githubga private qilib yubor OWNER/REPO`
- `ciber Vercelga production qilib deploy qil`
- `ciber exe yarat`
- `ciber diagnostika qil`
- `ciber shu faylni chuqur tekshir`

CIBER uses explicit, bounded tool adapters. It never treats arbitrary natural-language text as a shell command. External actions are verified before reporting PASS.
